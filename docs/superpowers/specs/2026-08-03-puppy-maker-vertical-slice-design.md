# Puppy Maker Vertical Slice Design

## 1. 목표

첫 버전은 기능 수를 늘리는 대신, 첨부 레퍼런스 화면의 인상과 밀도를 재현하는 데 집중한다. 사용자는 모바일 세로 화면에서 캐릭터 중심의 고급 애니메이션풍 육성 게임을 체험하고, 메인 로비 → 4주 스케줄 → 훈련 미니게임 → 대화 선택 → 월말 정산까지 하나의 플레이 루프를 완주할 수 있어야 한다.

## 2. 우선순위

1. 레퍼런스와 유사한 화면 밀도, 장식 프레임, 캐릭터 중심 구도
2. 세 화면 간 실제 상태 연결
3. 모바일 한 손 조작과 9:16 비율 대응
4. 이후 확장이 쉬운 데이터·화면 구조

기능을 많이 넣기 위해 에셋 품질을 낮추거나, 일반적인 웹 대시보드 UI로 대체하지 않는다.

## 3. 1차 구현 범위

### 메인 로비
- 따뜻한 판타지 실내 배경
- 중앙 수호 동물 캐릭터
- 상단 프로필, 골드, 보석, 달력, 날씨 HUD
- 측면 체력·피로·도덕·매력 상태
- 하단 스케줄, 가방, 퀘스트, 외출, 교감 메뉴
- 캐릭터 호흡, 부유 파티클, 버튼 눌림 효과

### 4주 스케줄
- 가죽 다이어리 형태의 주간 플래너
- 교육, 아르바이트, 휴식, 외출 활동 카드
- 4개 주차 슬롯에 탭 방식으로 활동 배치
- 자동 배치와 초기화
- 선택한 일정의 비용·보상·능력치 변화 즉시 표시

모바일에서 드래그만 강제하면 오조작이 잦으므로, 1차 버전은 탭 선택 후 슬롯 지정 방식을 기본으로 하고 데스크톱에서는 드래그도 지원한다.

### 훈련 미니게임
- 중앙 캐릭터와 훈련용 목각 인형
- 공격, 회피, 기 모으기 세 버튼
- 타이밍 구간, 콤보, 집중 게이지, 피로도
- 결과 등급 S/A/B/C와 능력치 보너스
- 짧은 이펙트와 화면 흔들림

### 대화 및 월말 정산
- 훈련 뒤 캐릭터 반응 대화
- 세 개 선택지와 즉시 상태 반영
- 4주 실행 결과 요약
- 다음 달로 이동

## 4. 비주얼 시스템

### 화면 구성
- 기준 캔버스: 390 × 844 CSS px
- 최소 지원 폭: 320 px
- 데스크톱에서는 중앙 모바일 프레임으로 표시
- 중요한 조작 요소는 하단 엄지손가락 영역에 배치

### 색과 재질
- 배경: 따뜻한 목재, 노을빛, 보랏빛 마법광
- 패널: 반투명 짙은 남색과 자주색 유리
- 테두리: 금빛과 청록빛 금속 장식
- 강조: 루비 레드, 사파이어 블루, 마법 퍼플
- 일반 웹 카드처럼 평면적인 흰색 사각형은 사용하지 않는다.

### 깊이 표현
- 외곽 금속 테두리
- 내부 유리광과 하이라이트
- 다중 그림자
- 마법 입자와 은은한 블룸
- 캐릭터·HUD·배경을 서로 다른 깊이 레이어로 분리

### 에셋 전략
- 레퍼런스 이미지를 그대로 재배포하거나 코드에 포함하지 않는다.
- 1차 코드에는 저장소에 안전하게 포함할 수 있는 CSS/SVG 장식과 자체 제작 플레이스홀더를 사용한다.
- 최종 캐릭터와 배경은 별도 생성·승인 후 WebP/PNG 에셋으로 교체할 수 있도록 경로를 분리한다.
- 캐릭터 이미지가 없어도 레이아웃과 상호작용 검증이 가능해야 하지만, 공개 데모 전에는 플레이스홀더를 제거한다.

## 5. 기술 구조

- React 19 + TypeScript + Vite
- React Router를 사용하지 않고 게임 상태에 따른 화면 전환으로 단순화
- Zustand 기반 단일 게임 스토어
- Framer Motion으로 화면 전환과 UI 모션 처리
- Vitest + React Testing Library
- CSS Modules 대신 기능별 스타일 파일과 공통 디자인 토큰 사용

### 주요 모듈
- `game/store`: 시간, 재화, 능력치, 일정, 현재 화면
- `game/content`: 활동과 대화 데이터
- `screens`: 로비, 스케줄, 미니게임, 대화, 정산
- `components/game-ui`: 프레임, 자원 표시, 상태 게이지, 게임 버튼
- `components/effects`: 파티클, 글로우, 화면 흔들림

## 6. 데이터 흐름

1. 로비에서 스케줄 화면 진입
2. 네 주의 활동을 선택
3. 일정 시작 시 주차별 활동 실행
4. 훈련 활동이면 미니게임 진입
5. 결과 점수를 능력치 보너스로 변환
6. 대화 선택 결과를 스트레스·호감도·도덕성에 반영
7. 나머지 주차를 자동 처리
8. 월말 정산 후 월과 주차를 갱신
9. 변경된 상태로 로비 복귀

## 7. 실패·예외 처리

- 일정이 비어 있으면 시작 버튼을 비활성화하고 부족한 주차를 표시
- 골드가 부족한 활동은 배치 불가
- 능력치는 지정된 최소·최대 범위로 제한
- 중복 클릭으로 미니게임 판정이 여러 번 적용되지 않도록 입력 잠금
- 저장 데이터 버전이 맞지 않으면 초기 상태로 안전 복구

## 8. 저장

1차 버전은 `localStorage`에 자동 저장한다. 서버와 로그인은 실제 반복 플레이가 검증된 뒤 추가한다. 초기부터 백엔드를 붙이면 디자인·게임성 검증보다 인증과 데이터 관리 비용이 커지므로 제외한다.

## 9. 테스트 기준

- 네 주 일정이 모두 배치되어야 실행 가능
- 활동 비용과 보상이 정확히 반영
- 미니게임 등급에 따라 훈련 보너스가 달라짐
- 대화 선택에 따라 상태값이 다르게 변화
- 월말 정산 후 월이 한 달 증가
- 320 px와 390 px 폭에서 주요 버튼이 화면 밖으로 벗어나지 않음

## 10. 완료 기준

- 메인 로비, 스케줄, 훈련, 대화, 정산이 끊김 없이 연결
- 새로고침 후 진행 상태 복원
- 모바일 세로 화면에서 레퍼런스와 유사한 장식 밀도와 깊이감 확보
- 이모지 기반 임시 아이콘을 핵심 UI에 사용하지 않음
- 테스트와 프로덕션 빌드 통과
