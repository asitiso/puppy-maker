## Architecture
Lane B adds one pure composition module. It does not add a map, stage, battle engine, save field, Story mutation, Bond mutation, App mount, or Root wiring.

The data flow is:

`CampaignWorldObjectiveDefinition`
→ lane encounter adapter
→ `CampaignEncounterDefinition`
→ `campaignEncounterToTacticalScenario`
→ `createTacticalScenarioBattle`
→ existing 3v3 Tactical engine/session
→ `resolveTacticalScenarioResult`
→ `handoffTacticalTerminalResult`
→ lane World outcome mapping
→ `resolveGuardianFestivalWorldOutcome`
→ canonical World Fact / fail-forward evidence.

## World objective to Tactical objective mapping
- `protect_residents` → `protect`
- `discover_route` → `escape`
- `remove_threat` → `target-elimination`
- `investigate_relic_rift` → `standard`

The lane uses the objective's first existing Expedition `stageId`. No new stage IDs are introduced.

For objective-specific IDs that depend on runtime units:
- `protect` targets `runa`, which is guaranteed to exist in the current 3v3 party constructor.
- `target-elimination` targets `${stageId}-enemy-1`, which is generated by the existing Tactical Expedition battle constructor.
- `escape` uses `afterRounds: 1`.

## Campaign modifier mapping
Only existing Spring Tactical modifier vocabulary is used:
- Caretaker → `{ campaign:'caretaker', kind:'protect', unitId:'runa' }`
- Pathfinder → `{ campaign:'pathfinder', kind:'escape', afterRounds:1 }`
- Vanguard → `{ campaign:'vanguard', kind:'elite', levelBonus:1 }`
- Arcanist → `{ campaign:'arcanist', kind:'rule-shift', ruleId:'world-objective' }`

These remain scenario metadata contracts; Lane B does not implement a second combat-effect engine.

## Terminal and World outcome mapping
The Tactical result remains combat-only. Lane B converts a handed-off terminal result to the World Guardian Festival resolver input:
- objective `success` + battle `victory` → `victory`
- objective `success` without battle victory (escape/survive style success) → `costly_victory`
- objective `failure` → `defeat`

`resolveGuardianFestivalWorldOutcome` remains the authority for canonical World Fact and fail-forward marker reconciliation. Lane B does not write Story/Bond state.

## Bond Intervention
Lane B may invoke the existing Tactical Bond Intervention hook before battle and at terminal timing. It passes only the existing `TacticalBondInterventionRequest`/response contract. It does not import or mutate `CharacterBondState`.

## Once-only handoff
The existing Tactical explicit `TacticalTerminalHandoffState` remains the dedupe authority. Lane B must apply World resolution only when `handoffTacticalTerminalResult` returns a non-null result. Replaying the same `scenarioId + attemptKey` produces no second World outcome application.
